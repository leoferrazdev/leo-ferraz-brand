# Leo Ferraz Brand System

Este repositório contém as fontes canônicas e implementações da identidade da marca Leo Ferraz.

## Fonte única da verdade

Nenhum agente deve inventar ou substituir uma decisão de marca quando existir uma especificação canônica aprovada.

## Estados documentais

```text
draft → review → approved → implemented
```

- `draft`: proposta em elaboração.
- `review`: aguardando decisão humana.
- `approved`: decisão canônica aprovada.
- `implemented`: decisão aprovada já refletida nos assets ou código correspondentes.

Conteúdo em `draft` ou `review` não deve ser tratado como decisão canônica.
