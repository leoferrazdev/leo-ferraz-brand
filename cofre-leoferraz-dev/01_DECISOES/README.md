# Decisões

Use esta área para registrar decisões operacionais, técnicas e de processo do projeto.

Cada decisão deve indicar contexto, alternativas consideradas, decisão tomada, autoridade, impacto, evidência e pendências. Uma decisão registrada aqui não altera automaticamente os documentos canônicos em `../brand/`.

> [!info] O que NÃO vai aqui
> Conteúdo produzido (roteiros, copy, textos publicáveis) vai em [[../03_CONTEUDO/README|03_CONTEUDO]], mesmo quando decorre de uma decisão registrada nesta pasta. Esta pasta é só para o registro da decisão em si — contexto, alternativas, escolha, autoridade.
