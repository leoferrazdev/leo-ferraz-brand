# Conteúdo

Use esta área para o texto integral de conteúdo produzido — roteiros, copy publicável, posts — quando o texto completo for grande o bastante para merecer arquivo próprio, separado do registro da decisão que o aprovou.

A decisão sobre o conteúdo (por que esse ângulo, alternativas consideradas, aprovação) continua em [[../01_DECISOES/README|01_DECISOES]]. Esta pasta guarda só o artefato final, versionado quando houver revisão relevante (ex.: `ROTEIRO-001`, v1 → v2).

## Convenção de nomes

```text
<TIPO>-<NNN> - <Título> (<qualificador opcional>).md
```

Tipos usados até agora: `ROTEIRO`, `COPY`, `PROMPT` e `GUIA`. Novos tipos (`POST`, `EMAIL`, etc.) seguem o mesmo padrão de numeração sequencial por tipo.
