## Brand as Code

> The Leo Ferraz Brand System is implemented as code. Documentation defines decisions, tokens encode them, components execute them, and the Living Brandbook demonstrates them.

```text
brand/BRAND_SYSTEM.md
→ release manifest / system index

specialized brand/*.md
→ canonical decision documents

tokens/tokens.json
→ canonical machine-readable implementation

src/components/brand/
→ executable projection

/brand/
→ public Living Brandbook
```
